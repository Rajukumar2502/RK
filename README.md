# Rajkumar PN — Static Portfolio

A standalone portfolio using **HTML + CSS + vanilla JavaScript**. No React, Emergent, npm, backend, or build step.

## Publish to GitHub Pages

1. Create a public GitHub repository (for example `portfolio`).
2. Upload **the contents of this folder** to the repository root, including `index.html`, `style.css`, `script.js`, `data.js`, `projects/`, `profile.png`, and `resume.pdf`.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Wait for GitHub to publish your site at `https://YOUR-USERNAME.github.io/portfolio/`.

## Edit later

- `data.js` — edit project titles, descriptions, categories, links, skills, career history, and other structured content.
- `index.html` — edit page layout, text, navigation, and contact details.
- `style.css` — edit colors, typography, sizing, and responsive design.
- `script.js` — edit filters, modal, and form interactions.
- `projects/` — add or replace images. Update paths in `data.js` accordingly.
- `resume.pdf` — replace with your newest resume.

## Notes

The contact form uses the Formspree endpoint from the original source. Verify that you own and have configured this Formspree form before relying on it. External Google Fonts and YouTube videos require internet access.

This is a **static reimplementation**, not a pixel-perfect React conversion. The portfolio content, images, project filters, project detail popups, resume download, and contact form have been carried over. Test the site and adjust styling if you want it to match the old version more closely.
